## Что добавил GLM-поиск

На сайте headless-браузером открыты rendered search-маршруты `GLM` и `Z.ai`; заголовки выдачи показывали 55 и 46 совпадений. Это счётчики выдач, они пересекаются и включают API, пополнения и мультисервисные ключи. После повторного прохода по Plati и GGSEL найдено 80 уникальных карточек-кандидатов: 33 Plati и 47 GGSEL. GGSEL-поиск расширен запросами `GLM`, `Z.ai`, `Z AI`, `GLM Coding`, `Zhipu`, `智谱`; их результаты объединяются с категорией, повторов в число карточек не добавляют. Покрытие карточек не означает, что каждый вариант имеет подтверждённую цену.

Фильтр discovery сохраняет брендовые карточки без срока в заголовке и смешанные карточки с подпиской и пополнением: вид выбранного варианта решает, является ли цена подпиской. Один новый смешанный товар Plati добавлен в raw; его Max/Pro/Lite цены не попали в рейтинг, потому что браузер не подтвердил выбор опции. Чистые API и пополнения в подписочный каталог не включаются.

## Расширение ChatGPT и Claude

Разные выдачи GGSEL через прокси давали разные ID. Повторный проход нашёл ещё 160 ChatGPT и 73 Claude объявления сверх первой выдачи; все ID добавлены в raw и отправлены на сбор цены. Часть страниц вернула HTTP 401 или timeout, поэтому для них цена осталась неподтверждённой. Сканер сохраняет такие ошибки и не публикует их как цены.

После первого прохода discovery был повторён с пределом 20 страниц:

- ChatGPT Plati: 211 ID, включая один новый ID без цены; GGSEL глубокий проход получил HTTP 401. Для GGSEL сохранена предыдущая успешная 6-страничная выборка из 196 ID, coverage остаётся `partial`.
- Claude Plati: повтор дал 112 ID без новых карточек; GGSEL глубокий проход получил HTTP 401. Сохранена успешная 6-страничная выборка из 141 ID.

Предел основного прохода — до 6 страниц на поисковый маршрут. Поэтому эти снимки шире предыдущих, но не являются переписью всех объявлений. Точные статусы, запросы и ошибки сохранены рядом с raw.

## LLM и качество

На историческом source-backed наборе из 15 вручную сверенных ChatGPT-вариантов адаптивный replay совпал с эталоном по 15/15 строк и по tier, сроку, способу выдачи и цене (15/15 по каждому полю). Правила без fallback дали 7/15 exact, сохранённый исторический LLM CSV — 12/15 exact. Это небольшой частичный benchmark, не оценка всего каталога; актуальный LLM API в этом проходе не вызывался.

Финальная независимая проверка отбрасывала только конкретный вариант, если браузер видел другую цену или не подтверждал выбор, затем проверяла следующего кандидата. Итог по семьям: MiniMax 24 winner / 16 rejected; GLM 10 / 36; ChatGPT 11 / 3; Claude 8 / 1; Kimi 5 / 17. Проверенные результаты остаются в `finalVerification.results`, отклонённые — в `rejectedResults`; отвергнутые цены исключены из рейтинга.
